# agentscan.space

Marketing site for the [agentscan](https://github.com/SimaAlexandru99/agentscan) CLI.

## Develop

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

## Deploy (Vercel)

Set the project **Root Directory** to `site`. Domain: `agentscan.space`.

See `PRODUCT.md` (copy intent) and `DESIGN.md` (Signal Amber system).
